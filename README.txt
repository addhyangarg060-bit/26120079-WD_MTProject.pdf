ADDHYAN GARG — PERSONAL PORTFOLIO
===================================

FILES
- index.html: website structure and content
- style.css: styling, colours, layout and responsive design
- Addhyan_Garg_Resume.pdf: downloadable resume linked from the homepage

PREVIEW
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Internet access is needed for the optional Google Fonts. System fallback fonts are included.

PUBLISH ON GITHUB PAGES
1. Create a public GitHub repository.
2. Upload index.html, style.css and Addhyan_Garg_Resume.pdf to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish your site.
